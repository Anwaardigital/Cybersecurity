کالی لینکس سیٹ اپ گائیڈ: اپنی اخلاقی ہیکنگ لیب بنائیں

آخری اپ ڈیٹ: 6 نومبر 2026

CyberSec Hub کی طرف سے · 10 منٹ مطالعہ
صرف اخلاقی استعمال: صرف ان سسٹمز کو ٹیسٹ کریں جو آپ کے اپنے ہوں یا جن کی ٹیسٹنگ کی آپ کے پاس تحریری اجازت ہو۔ بغیر اجازت ہیکنگ پاکستان اور دنیا بھر میں غیر قانونی ہے۔ یہاں موجود ہر چیز صرف دفاعی سیکیورٹی تعلیم اور مجاز ٹیسٹنگ کے لیے ہے۔

کالی لینکس سیکیورٹی ماہرین کے لیے سب سے مشہور آپریٹنگ سسٹم ہے — ایک لینکس ڈسٹری بیوشن جس میں سیکڑوں سیکیورٹی ٹیسٹنگ ٹولز پہلے سے موجود ہیں۔ یہ گائیڈ بتاتی ہے کہ اسے ورچوئل مشین میں محفوظ طریقے سے کیسے سیٹ کریں تاکہ آپ اپنے مین کمپیوٹر کو خطرے میں ڈالے بغیر یا کسی اور کے سسٹمز کو چھوئے بغیر الگ تھلگ لیب میں سیکھ سکیں۔

ورچوئل مشین کیوں (اپنا مین سسٹم نہیں)

سیکیورٹی ٹولز طاقتور ہیں، اور سیکھتے ہوئے غلطیاں ہوتی ہیں۔ ورچوئل مشین (VM) کالی کو آپ کے عام آپریٹنگ سسٹم کے اندر مہمان کے طور پر چلاتی ہے — مکمل طور پر الگ تھلگ۔ اگر کچھ خراب ہو جائے تو آپ VM ڈیلیٹ کر کے دوبارہ شروع کر دیتے ہیں؛ آپ کا اصل کمپیوٹر اچھوتا رہتا ہے۔ یہ علیحدگی اخلاقی مشق کے لیے ناقابل مذاکرات ہے۔

آپ کو کیا چاہیے

  • ایک کمپیوٹر جس میں کم از کم 8GB ریم (16GB بہتر) اور 40GB خالی ڈسک جگہ ہو۔
  • VirtualBox (مفت) یا VMware Workstation Player (ذاتی استعمال کے لیے مفت)۔
  • سرکاری kali.org ویب سائٹ سے کالی لینکس VM امیج — انسٹالیشن کی پریشانی سے بچنے کے لیے پہلے سے بنی VirtualBox/VMware امیجز استعمال کریں۔

مرحلہ وار سیٹ اپ

  1. VirtualBox ڈاؤن لوڈ کریں virtualbox.org سے اور انسٹال کریں۔
  2. کالی VM امیج ڈاؤن لوڈ کریں kali.org سے (VirtualBox 64-bit امیج چنیں)۔ سائٹ پر شائع شدہ ڈاؤن لوڈ چیک سم کی تصدیق کریں — یہ تصدیق کرتا ہے کہ فائل حقیقی اور غیر تبدیل شدہ ہے۔
  3. VM درآمد کریں: VirtualBox میں File ← Import Appliance، ڈاؤن لوڈ شدہ فائل منتخب کریں، اور ڈیفالٹ سیٹنگز سے درآمد کریں (اسے کم از کم 4GB ریم اور 2 CPU کور دیں)۔
  4. کالی شروع کریں اور لاگ ان کریں (ڈیفالٹ اسناد کالی کی دستاویزات میں شائع ہیں — فوراً بدل لیں)۔
  5. سب کچھ اپ ڈیٹ کریں: ٹرمینل کھولیں اور چلائیں sudo apt update && sudo apt full-upgrade -y۔ سیکیورٹی ٹولز کو تازہ رہنا چاہیے۔
  6. اسنیپ شاٹ لیں (VirtualBox: Machine ← Take Snapshot)۔ یہ آپ کا "ری سیٹ بٹن" ہے — ایک کلک کسی بھی وقت صاف لیب بحال کر دیتا ہے۔

اپنی لیب نیٹ ورک کو محفوظ طریقے سے ترتیب دیں

اپنی لیب کو الگ تھلگ رکھیں:

  • مشق ہدفوں کے لیے VirtualBox کا Host-only یا internal network موڈ استعمال کریں، تاکہ لیب ٹریفک کبھی آپ کے اصل نیٹ ورک یا انٹرنیٹ تک نہ پہنچے۔
  • اپنی حملہ VM کو کبھی ان نیٹ ورکس سے براہ راست نہ جوڑیں جن پر آپ کا مکمل کنٹرول نہ ہو۔
  • اپنے مشق ہدفوں (جیسے OWASP Juice Shop یا Metasploitable) کو اسی الگ تھلگ ورچوئل نیٹ ورک پر الگ VMs کے طور پر انسٹال کریں۔

پہلے دریافت کرنے کے لیے ضروری ٹولز (صرف اپنی لیب پر)

  • Nmap — اپنے ورچوئل نیٹ ورک پر نیٹ ورک دریافت (ہماری Nmap گائیڈ دیکھیں)۔
  • Wireshark — اپنی لیب کی ٹریفک دیکھیں (ہماری Wireshark گائیڈ دیکھیں)۔
  • Burp Suite — اپنی لیب ایپس کے خلاف ویب ایپ ٹیسٹنگ (ہماری Burp گائیڈ دیکھیں)۔
  • ٹرمینل کی بنیادی باتیں — ls، cd، ip a، ping، اور man سیکھیں؛ کمانڈ لائن سے سکون ہر چیز کی بنیاد ہے۔

اپنی لیب کے سنہری اصول

  • جو کچھ آپ کرتے ہیں وہ آپ کے VMs اور الگ تھلگ ورچوئل نیٹ ورک کے اندر رہتا ہے۔
  • واضح تحریری اجازت کے بغیر اپنی لیب سے باہر کسی چیز کو کبھی اسکین، جانچ، یا ٹیسٹ نہ کریں۔
  • اسنیپ شاٹس رکھیں تاکہ آپ ہمیشہ صاف ری سیٹ کر سکیں۔
  • جو سیکھیں اسے دستاویز کریں — اچھے نوٹس آپ کی مستقبل کی پیشہ ورانہ رپورٹس بن جاتے ہیں۔
آگے: لیب چلتے ہوئے ہماری طریقہ کار گائیڈ سے پیشہ ورانہ ورک فلو کی شروع سے آخر تک مشق کریں — محفوظ طریقے سے اپنے ماحول کے اندر۔

کالی کو اپ ڈیٹ اور صحت مند رکھنا

سیکیورٹی ٹولز تیزی سے پرانے ہو جاتے ہیں — پرانی کالی نئی چیکس سے محروم رہتی ہے اور خود بھی کمزوریاں رکھ سکتی ہے۔ اپنی VM کے اندر ماہانہ معمول:

sudo apt update && sudo apt full-upgrade -y
sudo apt autoremove -y

اگر اپ ڈیٹ کچھ توڑ دے تو آپ کا VirtualBox اسنیپ شاٹ سیکنڈوں میں آپ کو واپس لے جاتا ہے — اسنیپ شاٹس کے لازمی ہونے کی ایک اور وجہ۔ VirtualBox خود اور اس کا Extension Pack بھی کبھی کبھار اپ ڈیٹ کریں؛ ہوسٹ پر ورچوئلائزیشن کیڑے حقیقی حملہ سطح ہیں۔

سیکھنے کے لیے مفید حسب ضرورت تبدیلیاں

  • مشترکہ فولڈرز: اپنے نوٹس اور لیب فائلیں آسانی سے منتقل کرنے کے لیے ہوسٹ↔VM مشترکہ فولڈر سیٹ کریں (VirtualBox Guest Additions ضروری ہے)۔
  • تجربات سے پہلے اسنیپ شاٹس: انہیں وضاحتی نام دیں ("before-nmap-lab") تاکہ آپ حالتوں کے درمیان جا سکیں۔
  • ٹرمینل ملٹی پلیکسر: tmux کی بنیادی باتیں سیکھیں — ایک پین میں اسکین چلانے اور دوسرے میں نتائج پڑھنے کے لیے پینز الگ کریں۔
  • نوٹ لینا: لیب جرنل رکھیں (Obsidian، Joplin، یا سادہ مارک ڈاؤن) — ماہرین اپنے نوٹس میں رہتے ہیں۔

VM سے آگے کب جانا ہے

جب آپ آگے بڑھیں تو آپ وقف کالی لیپ ٹاپ یا Raspberry Pi لیب چاہ سکتے ہیں — لیکن صرف جب VM ورک فلو دوسری فطرت بن جائے۔ VM ضروری نظم سکھاتا ہے: الگ تھلگ، اسنیپ شاٹ شدہ، دستاویز شدہ مشق۔ ہارڈویئر اخلاقیات کے بارے میں کچھ نہیں بدلتا: ہر ہدف آپ کی اپنی لیب یا واضح طور پر مجاز سسٹم رہتا ہے۔

متبادل: WSL کے ذریعے ونڈوز پر کالی

اگر مکمل VM بھاری لگے تو ونڈوز صارفین WSL2 (Windows Subsystem for Linux) کے تحت کالی چلا سکتے ہیں — ہلکا، کالی ایپ Microsoft Store پر "Kali Linux" کے طور پر دستیاب ہے۔ انسٹال کریں، پھر اگر آپ GUI ٹولز چاہتے ہیں تو گرافیکل ڈیسک ٹاپ کے لیے Win-KeX پیکج شامل کریں۔ نقصانات: WSL نیٹ ورکنگ ونڈوز کے پیچھے NAT ہے، جو کچھ لیب نیٹ ورکنگ صورتحال کو پیچیدہ بناتا ہے، اور USB وائی فائی اڈاپٹر (اپنے نیٹ ورک پر وائرلیس مشق کے لیے) آسانی سے نہیں گزرتے۔ سنجیدہ لیب کام کے لیے VM بہتر رہتا ہے؛ WSL ہلکی شروعات کے لیے اچھا ہے۔

سیکیورٹی کام کے لیے ضروری لینکس کمانڈز

ان سے سکون روزانہ فائدہ دیتا ہے: ls -la، cd، pwd، cat/less، grep -r، find، chmod، ps aux، netstat -tulpn (یا ss -tulpn)، ip a، ping، curl، wget، tar، ssh، اور باقی سب کے لیے man <command>۔ انہیں اپنی کالی VM پر مشق کریں جب تک وہ عادت نہ بن جائیں — ہر اعلیٰ گائیڈ اس روانی کو فرض کرتی ہے۔

متعلقہ گائیڈز

  • Nmap شروعاتی گائیڈ: اپنا نیٹ ورک محفوظ طریقے سے اسکین کریں
  • پینٹریشن ٹیسٹنگ کیا ہے؟ اخلاقی ہیکنگ کی وضاحت
  • Metasploit کی بنیادی باتیں: پیشہ ورانہ فریم ورک سمجھنا (اخلاقی استعمال)
  • Wireshark کی بنیادی باتیں: اپنا نیٹ ورک ٹریفک دیکھیں (اپنا نیٹ ورک)
اپنی پیش رفت محفوظ کریں: گائیڈ مکمل کر لی؟ مکمل ہو گیا — صرف آپ کے براؤزر میں محفوظ ہے۔ اپنی پیش رفت اور لیڈر بورڈ دیکھیں۔
