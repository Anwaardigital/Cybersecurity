Wireshark کی بنیادی باتیں: اپنا نیٹ ورک ٹریفک دیکھیں (اپنا نیٹ ورک)

آخری اپ ڈیٹ: 6 نومبر 2026

CyberSec Hub کی طرف سے · 10 منٹ مطالعہ
صرف اخلاقی استعمال: صرف ان سسٹمز کو ٹیسٹ کریں جو آپ کے اپنے ہوں یا جن کی ٹیسٹنگ کی آپ کے پاس تحریری اجازت ہو۔ بغیر اجازت ہیکنگ پاکستان اور دنیا بھر میں غیر قانونی ہے۔ یہاں موجود ہر چیز صرف دفاعی سیکیورٹی تعلیم اور مجاز ٹیسٹنگ کے لیے ہے۔

Wireshark دنیا کا سب سے زیادہ استعمال ہونے والا نیٹ ورک پروٹوکول تجزیہ کار ہے — مفت، اوپن سورس، اور نیٹ ورک انجینئرز اور سیکیورٹی ماہرین کا معیاری سامان۔ یہ آپ کے اپنے نیٹ ورک انٹرفیس سے گزرنے والے پیکٹس کو پکڑتا ہے اور انہیں پڑھنے کے قابل شکل میں دکھاتا ہے۔ یہ گائیڈ جائز استعمال سکھاتی ہے: اپنی ٹریفک کو سمجھنا، اپنے نیٹ ورک مسائل کی تشخیص کرنا، اور پروٹوکولز کیسے کام کرتے ہیں یہ سیکھنا۔

Wireshark آپ کو کیا دکھاتا ہے

ہر بھیجی گئی ای میل، ہر لوڈ شدہ صفحہ، ہر اسٹریم شدہ ویڈیو پیکٹس میں ٹوٹ جاتی ہے — ماخذ، منزل، اور مواد والے ڈیٹا کے چھوٹے لفافے۔ Wireshark ان لفافوں کو پکڑتا ہے جب وہ آپ کے کمپیوٹر کے نیٹ ورک کارڈ سے گزرتے ہیں اور انہیں ڈی کوڈ کرتا ہے: "یہ پیکٹ ویب صفحہ لوڈ کا حصہ ہے،" "یہ example.com کے لیے DNS تلاش ہے۔" اصل ٹریفک دیکھنا تجریدی نیٹ ورکنگ تصورات کو ٹھوس بنا دیتا ہے۔

Wireshark انسٹال کرنا

صرف سرکاری wireshark.org سائٹ سے ڈاؤن لوڈ کریں۔ ونڈوز پر انسٹالر میں Npcap (کیپچر ڈرائیور) شامل ہے — اسے قبول کریں۔ لینکس پر: sudo apt install wireshark (روٹ کے بغیر کیپچر کرنے کے لیے اپنے صارف کو wireshark گروپ میں شامل کریں)۔ macOS پر سرکاری ڈسک امیج سے انسٹال کریں۔ سیٹ اپ کے دوران آپ سے کیپچر اجازتوں کے بارے میں پوچھا جائے گا — انہیں صرف اپنے سیکھنے کے استعمال کے لیے دیں۔

آپ کی پہلی کیپچر (آپ کی اپنی ٹریفک)

  1. Wireshark کھولیں۔ آپ کو اپنے کمپیوٹر کے نیٹ ورک انٹرفیسز کی فہرست نظر آئے گی۔
  2. اپنے کمپیوٹر کی ٹریفک پکڑنا شروع کرنے کے لیے اپنے فعال انٹرفیس (وائی فائی یا ایتھرنیٹ) پر ڈبل کلک کریں۔
  3. اپنے براؤزر میں ویب سائٹ کھولیں، پھر Wireshark پر واپس جائیں اور روکنے کے لیے سرخ مربع پر کلک کریں۔
  4. اب آپ کے پاس ان پیکٹس کی فہرست ہے جو آپ کے کمپیوٹر نے بھیجے اور وصول کیے۔ کسی بھی پیکٹ پر کلک کریں تاکہ اس کی ڈی کوڈ شدہ تہیں دیکھیں — ایتھرنیٹ، IP، TCP/UDP، اور ایپلیکیشن ڈیٹا۔

فلٹرنگ: سگنل تلاش کرنا

اصل کیپچرز میں ہزاروں پیکٹس ہوتے ہیں۔ ڈسپلے فلٹر بار آپ کی سب سے اہم مہارت ہے:

  • dns — صرف DNS تلاشیں دکھائیں (آپ کے کمپیوٹر نے کن ناموں کو حل کیا)۔
  • http — HTTP ٹریفک دکھائیں۔
  • ip.addr == 192.168.1.1 — آپ کے اپنے راؤٹر سے متعلق ٹریفک۔
  • tcp.port == 443 — خفیہ ویب ٹریفک۔

اپنی کیپچر پر یہ مشق آزمائیں: dns فلٹر کریں اور دیکھیں کہ براؤز کرتے ہوئے آپ کے کمپیوٹر نے کن ویب سائٹس کو تلاش کیا۔ آنکھیں کھولنے والا — اور مکمل آپ کا اپنا ڈیٹا۔

اپنی ٹریفک سے سیکھنے کی جائز چیزیں

  • کون سی ایپس "فون ہوم" کرتی ہیں: اپنے فون یا PC کی ٹریفک سے فلٹر کریں اور دیکھیں کہ آپ کا اپنا سافٹ ویئر پس منظر میں کن کنکشنز بناتا ہے — پرائیویسی آگاہی کے لیے بہترین۔
  • اپنے مسائل کی تشخیص: سست کنکشن؟ اس دوران کیپچر کریں اور دوبارہ منتقلی اور DNS تاخیر تلاش کریں۔
  • پروٹوکول سیکھنا: TCP ہینڈ شیک (SYN، SYN-ACK، ACK) لائیو ہوتے دیکھیں — کتابیں مقابلہ نہیں کر سکتیں۔
  • خفیہ کاری چیک کرنا: تصدیق کریں کہ آپ کی بینکنگ اور ای میل واقعی TLS استعمال کرتی ہیں (پڑھنے کے قابل مواد نہیں، TLS ہینڈ شیک تلاش کریں)۔

آپ کو کیا نہیں کرنا چاہیے

  • ان نیٹ ورکس پر کبھی ٹریفک کیپچر نہ کریں جو آپ کے اپنے نہیں ہیں یا جن کا آپ انتظام نہیں کرتے — دوسروں کی بات چیت روکنا زیادہ تر ممالک میں غیر قانونی ہے، حتیٰ کہ "صرف دیکھنا" بھی۔
  • مشترکہ یا عوامی نیٹ ورکس پر صرف واضح تحریری اجازت سے کیپچر کریں (مثلاً، آپ کے آجر کا نیٹ ورک آپ کے کام کے حصے کے طور پر، منظوری کے ساتھ)۔
  • خفیہ ٹریفک (HTTPS) ڈیزائن سے ناقابل پڑھنے ہے — "دوسروں کی ٹریفک ڈی کرپٹ کرنے" کا دعویٰ کرنے والے ٹولز یا تو فراڈ ہیں یا حملہ ٹولز۔ وہاں نہ جائیں۔
Nmap کے ساتھ جوڑیں: اپنے نیٹ ورک کے آلات کا نقشہ بنانے کے لیے ہماری Nmap گائیڈ استعمال کریں، پھر Wireshark سے دیکھیں کہ وہ آلات واقعی کیا کہتے ہیں۔ ساتھ وہ آپ کو نیٹ ورکنگ کے بارے میں کسی بھی کورس سے زیادہ سکھاتے ہیں۔

TCP اسٹریم کی پیروی کرنا (آپ کی اپنی ٹریفک)

اپنے براؤزنگ سیشن سے کسی بھی TCP پیکٹ پر دائیں کلک کریں اور Follow ← TCP Stream چنیں۔ Wireshark پوری گفتگو کو دوبارہ بناتا ہے — آپ اپنے براؤزر کی درخواست اور سرور کا جواب پڑھنے کے قابل متن کے طور پر دیکھیں گے (اپنے لیب سرور پر غیر خفیہ HTTP کے لیے)۔ یہ سمجھنے کا واحد بہترین طریقہ ہے کہ "ویب درخواست" دراصل کیا ہے۔ اسے اپنے لیب ویب سرور کے خلاف آزمائیں جو سادہ HTTP چلا رہا ہے، پھر HTTPS سائٹ سے موازنہ کریں جہاں آپ صرف خفیہ بکواس دیکھیں گے — خفیہ کاری کیوں اہم ہے اس کا جذباتی سبق۔

شماریات: نمونے دیکھنا

Wireshark کا Statistics مینیو پیکٹ فہرستوں میں پوشیدہ نمونے ظاہر کرتا ہے: Protocol Hierarchy دکھاتا ہے کہ آپ کی ٹریفک کا کتنا حصہ DNS، TCP، UDP ہے؛ Conversations فہرست کرتا ہے کہ کس نے کس سے بات کی اور کتنا؛ IO Graphs وقت کے ساتھ ٹریفک پلاٹ کرتے ہیں — چوٹیاں اس ویڈیو کال یا ڈاؤن لوڈ سے میل کھاتی ہیں۔ اپنے نیٹ ورک پر یہ نظارے "میرا نیٹ ورک واقعی کیا کر رہا ہے؟" کا جواب کسی بھی ڈیش بورڈ سے تیزی سے دیتے ہیں۔

کیپچر فلٹرز بمقابلہ ڈسپلے فلٹرز

شروعاتیوں کو فرق جاننا چاہیے: کیپچر فلٹرز (کیپچر سے پہلے سیٹ کیے گئے، مثلاً port 80) طے کرتے ہیں کہ کیا ریکارڈ ہوتا ہے — غیر ریکارڈ شدہ ٹریفک ہمیشہ کے لیے گئی۔ ڈسپلے فلٹرز (مین بار) صرف پہلے سے مکمل کیپچر سے چھپاتے/دکھاتے ہیں۔ اصولی قاعدہ: اپنے انٹرفیس پر وسیع کیپچر کریں، بعد میں تنگ فلٹر کریں۔ ڈسک سستی ہے؛ چھوٹے پیکٹس ناقابل بازیاب ہیں۔

مفید ڈسپلے فلٹرز کتابچہ (آپ کی ٹریفک)

  • dns.qry.name contains google — google سے متعلق DNS تلاشیں۔
  • http.request.method == "POST" — آپ کی اپنی براؤزنگ سے فارم جمع کرانے۔
  • tcp.analysis.retransmission — دوبارہ بھیجے گئے پیکٹس، آپ کے کنکشن پر نیٹ ورک پریشانی کی نشانی۔
  • dhcp — دیکھیں کہ آپ کا آلہ وائی فائی جوائن کرتے وقت اپنا IP پتہ کیسے حاصل کرتا ہے۔
  • arp — آپ کے LAN پر پتہ حل کرنے کی بات چیت۔

جن فلٹرز کو آپ دوبارہ استعمال کرتے ہیں انہیں محفوظ کریں (فلٹر بار پر دائیں کلک کریں ← محفوظ کریں)۔ فلٹرز کا ذاتی کتابچہ کام کرنے والے تجزیہ کار کا خزانہ ہے۔

اپنی کیپچرز سے ثبوت برآمد کرنا

File ← Export Objects ← HTTP آپ کو اپنی کیپچر میں منتقل شدہ فائلیں محفوظ کرنے دیتا ہے — یہ جانچنے کے لیے مفید ہے کہ آپ کے لیب سرور نے کیا بھیجا تھا۔ Statistics ← Protocol Hierarchy رپورٹس میں اچھی طرح برآمد ہوتا ہے۔ اور یاد رکھیں: کیپچر فائلوں میں حساس ڈیٹا ہو سکتا ہے (حتیٰ کہ آپ کا اپنا)، اس لیے انہیں محفوظ طریقے سے محفوظ کریں اور کام مکمل ہونے پر ڈیلیٹ کریں۔ ماہرین pcaps کو ثبوت کی طرح سمجھتے ہیں — کیونکہ وہ ہیں۔

متعلقہ گائیڈز

  • Nmap شروعاتی گائیڈ: اپنا نیٹ ورک محفوظ طریقے سے اسکین کریں
  • کالی لینکس سیٹ اپ گائیڈ: اپنی اخلاقی ہیکنگ لیب بنائیں
  • Nmap کی اعلیٰ تکنیکیں: اپنے نیٹ ورک کی گہری اسکیننگ
  • پینٹریشن ٹیسٹنگ طریقہ کار: پیشہ ورانہ ورک فلو
اپنی پیش رفت محفوظ کریں: گائیڈ مکمل کر لی؟ مکمل ہو گیا — صرف آپ کے براؤزر میں محفوظ ہے۔ اپنی پیش رفت اور لیڈر بورڈ دیکھیں۔
